# 结构化学习法

> **定位**: Knowledge-IN 流程的核心执行标准。分两级：先选提取方法（怎么学），再定存储策略（存哪里）。
> **v4.0 新增**：正误对照示例 + 系统性降级路径 + 执行前自检闸门

## 文件类型 → 路由速查

| 来源目录 | 文件类型 | 提取方法 | 存储位置 |
|---------|---------|---------|---------|
| raw/policy/ | 中央/省级政策 | 政策学习法 | wiki/concepts/ |

## 方法选择自检 `CRITICAL`

> 每次进入 Step 4 前必须通过此自检。

```
□ 文件类型识别正确？政策类 / 案例类 / 学术类 — 三者互斥，一次只选一种
□ 是否已确认源文件目录？（raw/policy/ vs raw/sources/ vs raw/documents/）
□ 制度定位句式已用正则（把.*作为、把.*放在、以.*为）全文检索？
```

# 第一篇：提取方法

> 根据文件类型选择对应的提取方法。三种方法互斥，一次只选一种。

---

## 一、政策学习法

**适用**: raw/policy/（中央/省级政策）、raw/documents/、raw/practice/（本校工作要点、报告、讲话）

**目标**: 上级政策 → 知导向、明底线、抓重点、转行动；本校文件 → 存史实、备调用

### 5 步流程

**Step 1 — 抓总**: 总体思路 + 核心目标 + 关键词体系

```
**总体思路**: [原文关键表述]
**核心目标**: [量化 + 定性]
**关键词体系**: [关键词1, 关键词2, ...]
```

> **奋斗目标/展望表述 — 重点提取**: 政策文件中"为...努力奋斗""加快构建...""奋力推进...""全面建设...""着力打造..."等展望性语句，往往是发展目标和方向的凝练概括。此类表述**全文照录**，不简化。

```
**奋斗目标**: [原文展望/号召性表述，全文照录]
```

> **制度定位表述 — 强制收录** `HARD LIMIT`: 政策文件中"把...作为...""把...放在...""以...为..."等句式，表达的是"什么等于什么"的根本判断——制度定位、根本标准、核心关系，是政策逻辑的骨架。**必须全文照录，附条文编号**，不可简化为要点概括。

```
**制度定位（原文照录）**:
> **（第X条）** 把[对象]作为/放在[定位]，......
```

**搜索方法**: 在源文件中检索 `把.*作为`、`把.*放在`、`以.*为` 等正则模式。
**存储位置**: 在概念页的对应制度板块开头，以"制度定位（原文照录）"或"根本定位（原文照录）"子标题呈现。

### 抓总示例

✅ **CORRECT**:
```
**总体思路**: "以习近平新时代中国特色社会主义思想为指导，全面落实党的教育方针，
  以师范类专业认证为抓手，推动教师教育高质量发展"
**核心目标**: 2026年完成二级认证专业≥15个，三级认证实现突破
**关键词体系**: 师范认证、二级认证、三级认证、教师教育、质量保障
```
→ 总体思路照录原文关键句，核心目标量化，关键词精准

❌ **INCORRECT**:
```
**总体思路**: 加强师范教育
**核心目标**: 提高质量
```
→ 错误原因：过度简化，丢失了原文的政策逻辑和量化指标

---

**Step 2 — 拆块**: 按文件内在逻辑拆分为板块，标注关系（并列/递进/从属）

### 拆块示例

✅ **CORRECT**:
```
**板块一：总体要求与指导思想**（总领）
**板块二：重点任务**（并列，5项）
  - 任务1：深化师范类专业认证改革
  - 任务2：加强教师教育课程建设
  - ...
**板块三：保障措施**（从属，支撑板块二）
  - 组织保障
  - 经费保障
  - 督导评估
```
→ 板块按政策内在逻辑拆分，关系明确标注

❌ **INCORRECT**:
```
**一、开头**
**二、中间部分**
**三、结尾**
```
→ 错误原因：使用模糊的"开头/中间/结尾"代替按政策逻辑拆分的板块，且未标注关系

---

**Step 3 — 逐条提炼**: 保留原文动词 + 责任单位 + 数据指标

```
| 序号 | 核心要点 | 责任单位 | 关键词 |
|------|---------|---------|--------|
| 1 | [原文关键表述，含动词] | [单位] | [关键词] |
```

### 逐条提炼示例

✅ **CORRECT**:
```
| 1 | 推进师范类专业二级认证全覆盖，2026年完成≥15个专业认证 | 教务处、质评中心 | 师范认证、二级认证 |
```
→ 保留了原文动词"推进""完成"，标注了责任单位和量化指标

❌ **INCORRECT**:
```
| 1 | 搞认证 | 相关部门 | - |
```
→ 错误原因：动词弱化（推进→搞），责任单位模糊，量化指标丢失

---

**Step 4 — 主要精华**: 要点表 / 金词库 / 可复用材料 / 关联更新

**Step 5 — 行动清单**（上级政策专属，本校文件可跳过）:

```
行动清单:
  1. [具体行动] — 时限：[短期/中期/长期]
```

### 行动清单示例

✅ **CORRECT**:
```
行动清单:
  1. 对照2026年师范认证新标准，梳理本校师范类专业达标差距 — 时限：短期（1个月内）
  2. 启动"AI+教师教育"特色课程建设试点 — 时限：中期（本学期内）
```

❌ **INCORRECT**:
```
行动清单:
  1. 好好学习政策精神
```
→ 错误原因：不可操作，无时限，无法追踪

---

### 政策学习法降级路径 `IMPORTANT`

| 场景 | 主方案 | 降级方案 |
|------|--------|---------|
| 文件 >500 行 | 5 步完整流程 | 抓总→拆块→选重点板块提炼（至少覆盖前 3 个板块），其余板块概述 |
| 文件无明确条文编号 | 按条款号引用 | 按自然段落引用（如 `第X段`） |
| 文件中制度定位句式不明确 | 全文搜索 `把.*作为\|以.*为` | 手动阅读全文，标注隐含的制度定位表述 |
| 文件涉及多个责任单位交叉 | 逐一标注 | 标注牵头单位，其余单位用"等单位"概括 |

---

### 动词保留
必须保留：实施、推进、开展、强化、完善、力争、实现、达到、确保、完成
效果动词：形成、构建、打造、完成
禁止：替换为弱动词（"做""搞""抓"）

### 禁止事项
- `HARD LIMIT` ❌ 简化政策表述（制度定位句式原文照录，不失真）
- `CRITICAL` ❌ 遗漏责任单位和数据指标
- `HARD LIMIT` ❌ "幻想"（捏造不在原文中的表述）

## 二、案例拆解法

**适用**: raw/sources/ 下的高校典型案例/战线联播文章

**目标**: 学思路、借举措、拓视野 → "他们怎么思考问题、怎么解决问题"

### 四问拆解

```
[问1] 背景与问题：他们面对什么困境/挑战？为什么需要解决？
[问2] 解题思路：他们怎么分析问题？核心逻辑是什么？
[问3] 关键举措：具体做了什么？（闪光点的集中地，原文照录）
[问4] 成效与启示：结果如何？对我们有什么可借鉴的？
```

### 四问拆解示例

✅ **CORRECT** — 中国传媒大学教育教学改革案例:
```
[问1] 背景与问题：传媒行业数字化转型加速，传统新闻传播类专业的课程体系
  与行业需求脱节，毕业生实践能力不足
[问2] 解题思路：以"融媒体"为核心概念重构课程体系，将行业真实项目引入课堂
[问3] 关键举措：
  - 与央视、新华社共建"融媒体实验室"，学生参与真实项目制作（原文照录）
  - 推行"双师制"，业界导师占比≥40%（原文数据）
  - 建立"课程—项目—作品"三级实践教学链
[问4] 成效与启示：毕业生融媒体岗位就业率提升 23%；对我校的启示——可借鉴
  "双师制"模式，与本地媒体共建实践平台
```

❌ **INCORRECT**:
```
[问1] 背景与问题：学校需要改革
[问3] 关键举措：做了一些改革
```
→ 错误原因：[问1]不具体（什么背景？什么问题？）；[问3]架空（什么举措？谁做的？）

---

### 双写规则

案例材料**同时写入两个位置**：

| 写入位置 | 内容 | 格式 |
|---------|------|------|
| wiki/entities/机构-XX大学.md | 学校简述 + 特色标签 | 简要条目 |
| wiki/concepts/对应概念页 | 具体举措 + 可借鉴点 | 新增"他校实践"板块 |

**概念页中的"他校实践"板块格式**:
```
## 他校实践

### [学校名] — [经验主题]
- **背景**: [一句话]
- **举措**: [关键做法，3-5条]
- **可借鉴**: [对我们的启示]
```

### 双写示例

✅ **CORRECT**:
```markdown
## 他校实践

### 中国传媒大学 — 融媒体课程体系改革
- **背景**: 传媒行业数字化转型，传统课程体系与行业需求脱节
- **举措**: 共建融媒体实验室、推行双师制（业界导师≥40%）、建立三级实践教学链
- **可借鉴**: 与本地媒体共建实践平台，引入双师制
```

❌ **INCORRECT**: 只在 `wiki/entities/机构-中国传媒大学.md` 写了条目，概念页没有"他校实践"板块
→ 错误原因：双写规则要求两个位置都要写入，否则信息孤岛

---

### 案例拆解法降级路径 `IMPORTANT`

| 场景 | 主方案 | 降级方案 |
|------|--------|---------|
| 案例信息不全（缺背景） | 四问全部回答 | 已有信息正常提取，缺失字段标注"原文未提供" |
| 案例信息不全（缺成效） | 四问全部回答 | [问4] 标注"原文未提供成效数据"，不编造 |
| 案例涉及多所学校 | 逐校拆解 | 选 2-3 个最具代表性的学校重点拆解，其余简述 |
| 案例与本校关联度低 | 正常拆解+双写 | 双写不变，但在"可借鉴"中标注"关联度：低" |

---

### 禁止事项
- `HARD LIMIT` ❌ 将他校经验混淆为本校做法
- `CRITICAL` ❌ 只存实体页不写概念页（信息孤岛）
- `IMPORTANT` ❌ 架空举措（不提取具体做法）

## 三、观点萃取法

**适用**: raw/sources/ 或 raw/research/ 下的学术文章、专家访谈

**目标**: 看趋势、预判方向 → 提取前瞻性判断

### 3 步流程

**Step 1 — 抓核心观点**: 作者的核心判断（1-3 条，原文引用）

```
核心观点:
  1. "[原文关键判断]"
```

**Step 2 — 列关键论据**: 支撑观点的数据/事实/逻辑

**Step 3 — 判趋势信号**: 指向什么变化？对实务意味着什么？

```
趋势信号:
  - 政策方向：[预判]
  - 实务影响：[对本校工作的启示]
```

### 观点萃取示例

✅ **CORRECT** — 顾明远《师范院校当更有作为》:
```
核心观点:
  1. "师范院校在教师教育中的主体地位不可替代，综合大学无法覆盖基础教育全科需求"
  2. "AI时代教师角色从知识传授者转向学习设计者，师范院校需率先完成这一转型"

关键论据:
  - 全国1800万教师中，师范院校毕业生占比仍在85%以上（数据支撑观点1）
  - AI教育工具渗透率年增40%，但教师AI素养培训覆盖率不足15%（数据支撑观点2）

趋势信号:
  - 政策方向：师范院校的主体地位短期内不会动摇，但要加速数字化能力建设
  - 实务影响：本校应优先布局"AI+教师教育"课程体系，抢占转型先机
```

❌ **INCORRECT**:
```
核心观点:
  1. "师范院校很重要"（不是原文引用，是主观概括）
  
趋势信号:
  - 以后AI会很重要（没有具体指向，没有对本校的启示）
```
→ 错误原因：核心观点必须原文引用（带引号），趋势信号必须具体到政策方向和实务影响

---

### 写入位置

`wiki/concepts/对应概念页`，新增"前沿观点"板块：

```
## 前沿观点

> 来源：[文章/访谈名]，[作者]，[日期]

**核心判断**: [原文引用]

**趋势信号**: [对本校实务的启示]
```

### 观点萃取法降级路径 `IMPORTANT`

| 场景 | 主方案 | 降级方案 |
|------|--------|---------|
| 文章无明确核心判断 | 提取核心观点（原文引用） | 从论证逻辑中归纳，标注"归纳自原文论证"，不编造原文不存在的判断 |
| 文章缺数据支撑 | 列出关键论据（含数据） | 列出逻辑论据（无数据时），标注"原文未提供量化数据" |
| 趋势信号不明确 | 判趋势信号（政策+实务） | 注明"该文趋势信号不明确"，仅提取核心观点 |
| 多篇文章观点冲突 | 分别提取，标注冲突 | 在概念页中并置两种观点，标注"观点分歧"，不自行判定对错 |

---

### 禁止事项
- `HARD LIMIT` ❌ 混淆作者观点与政策规定（观点≠政策）
- `IMPORTANT` ❌ 将趋势预判当作既定事实
- `IMPORTANT` ❌ 在观点冲突时自行判定对错（应并置标注"观点分歧"）

# 第二篇：存储策略

> 提取完成后，决定内容写入哪个文件。上级政策/案例/学术直接写入对应 wiki 页面，本校文件需三层分流。

---

## 本校材料三层分流

| 层级 | 目标文件 | 内容范围 | 更新频率 |
|------|---------|---------|---------|
| **稳定层** | wiki/entities/机构-齐鲁师范学院.md | 学校概况、定位、战略、党建体系、文化品牌、领导分工 | 低频，重大变化时更新 |
| **年度层** | wiki/entities/本校-年度工作要点-YYYY.md | 年度工作要点、任务指标、教代会报告目标 | 每年一个文件 |
| **事件层** | wiki/entities/本校-重要会议与讲话.md | 会议讲话原文、年度成效数据、专项部署 | 每次重要事件后追加 |

### 分流判断

| 内容特征 | 归入层级 |
|---------|---------|
| "学校占地X亩""本科专业X个"等基本数据 | 稳定层 |
| "122N体系""君子文化"等框架性表述 | 稳定层 |
| "2026年目标：国家级项目≥12项"等年度指标 | 年度层 |
| "2025年获批省部级项目40项"等成效数据 | 事件层 |
| 领导在某会议上的讲话原文 | 事件层 |
| 领导分工调整 | 稳定层 |

### 分流判断示例

✅ **CORRECT**:
- "学校现有本科专业 42 个" → 稳定层（基本数据，长期不变）
- "2026年力争获批国家级项目 ≥12 项" → 年度层（有时效性的目标指标）
- "2025年我校获批国家自然科学基金项目 8 项" → 事件层（已发生的成效统计）

❌ **INCORRECT**:
- "2026年目标：新增硕士点 3 个" → 写入了稳定层
- 错误原因：年度目标指标不应写入稳定层，应写入年度层，否则过期后成为错误数据

---

### 提取比例
- 稳定层：精简至 120 行以内
- 年度层：40% 原文引用
- 事件层：60% 原文引用（保留语境）

### 禁止事项
- `CRITICAL` ❌ 年度指标写入稳定层（造成过期数据）
- `IMPORTANT` ❌ 会议讲话要点遗漏
- `GUIDELINE` ❌ 稳定层超过 150 行

# 通用防遗忘清单

> 以下核查点已嵌入各方法的执行流程中，此处为全局汇总。

```
□ L1 文件类型识别正确？提取方法选对？
□ L1 制度定位句式原文照录（附条文编号）？
□ L1 无"幻想"内容？
□ L1 标签来自 tag-index.md？
□ L2 提取步骤完整？
□ L2 本校文件：三层分流判断正确？
□ L2 责任单位/数据指标原文照录？
```
