# 人民论坛评论写作范式

> 来源：人民日报评论《"人民论坛"征稿啦！》（2025-11-19），含栏目定位 + 4 篇范文。投稿信息见 [[个人-专业发展]]。

## 适用场景

向人民日报"人民论坛"栏目投稿，或撰写同风格时评。

## 默认画像（可替换）

**默认**：作者本人（[[人物-侯伟]]）。可指定其他画像（如"以党委书记画像视角切入"写书记向评论），**复用该画像的思维模式/关注侧重/话语体系**，结构骨架仍为本文范式。

> ⚠ **署名边界**：人民论坛评论是**作者署名**文体——画像仅提供"像X那样想问题"的思维/侧重/话语资源，画像观点作引用素材；**不得以画像名义/第一人称口吻代笔**（如写顾明远画像勿写"我这一生从教七十余年"，应写"顾明远认为…"）。详见 `schema/4.writing-guide.md` §四「画像使用边界」。

## 栏目定位（原文照录）

> 多从小切口反映大主题、大道理，以新立意解析"国之大者"，以新视角审视天下经纬，以新故事照见新时代的火热实践，**重在当下针对性，重在观点的启迪性**。

## 投稿硬信息

| 项目 | 内容 |
|------|------|
| 字数 | 1400 字以内 |
| 选题 | 发展之道、治理智慧、党性修养、成长感悟 |
| 邮箱 | rmrbpl@peopledaily.cn（主题注明"人民论坛"） |
| 要求 | 稿件即正文；留真实姓名/电话/地址/邮编；见报后寄稿费 |

## 四种范式

### 1. 意象统摄（《从旗帜感悟胜利之源》桂从路）

一个意象贯穿全篇，分三层（方向-信念-力量）；具体场景起笔 + 历史纵深 + 短句对仗。

### 2. 预言对照（《三则"预言"看未来》常晋）

三组"预言 vs 现实"对比（孙中山铁路/钱学森汽车/电影票房），落到信心-创新-耐心；用具体数字制造落差。

### 3. 劳动起兴（《担麦与担事》王锦涛）

从劳作细节起兴迁移到宏大命题（担麦→担事）；分三组对应（舍不得-停不得-歇不得）+ 典型人物事例支撑。

### 4. 生活隐喻（《"养鱼"与"养水"》崔妍）

从生活小事引入作比（养鱼→市场活水）；隐喻层层升格（活水→慢换水→温柔→格局）+ 现实案例。

## 共通写法

1. 小切口反映大主题、大道理
2. 三层结构展开
3. 新立意新视角（解析"国之大者"）
4. 重当下针对性、重观点启迪性
5. 字幅克制 ≤1400 字
6. **素材多元**：综合政策依据、时事热点、数据、多方观点——**忌变成"单一人物的观点综述"**（点名引用某专家 ≤1-2 处，其余转为"共识/有识之士"并与其他观点并置）`CRITICAL`
7. **问题破解（评论核心）**：立意只是起点，**破题路径才是核心**——点出问题的关键点/卡点/痛点，一一对应给解法，不满足于"立意正确但阐述空泛"
8. **数据可溯源** `HARD LIMIT`：文中的每个具体数据（数字/百分比/人名/头衔/成果）都必须在 source 或知识库有出处——无源数据即废（CLAUDE.md §九 引文纪律第6条），宁用定性表述或换有源数据
9. **引文纪律**：按 CLAUDE.md §九「引文纪律」六条执行——加引号=原文照录、数据保留限定条件（样本/时间/范围）、跨场合金句标注语境、转引标注"援引"、政策/模式归属准确

## 执行要点

- 选题：从"习以为常里藏着选题"出发（见 [[评论素养]]）
- 切入：**面向基层实践**——以具体学校/岗位/场景为切入点（如"以师范院校为例"），**寻求政策依据 + 创新实践**支撑，让文章丰满、有说服力（评论文章的核心与关键）`CRITICAL`
- 素材：**多源汇聚**——政策原文 + 时事事件 + 具体数据 + 典型人物事例 + 不同学者观点，不围着单一来源转
- 语言：短句、对仗、避免 AI 腔与口号堆砌；**去AI味按 schema/4 §三-A 清单逐项过**（正文破折号清零、句式去模板、动词去同质化、意象词收敛、升华腔克制、引号节制、数据叙事化）
- 原创：严禁 AI 直接生成（投稿硬要求）

## 自检清单

- [ ] 小切口起笔、落到大主题
- [ ] 三层结构
- [ ] 原创、无 AI 腔（schema/4 §三-A 逐项过）
- [ ] 字数 ≤1400
- [ ] 针对性 + 启迪性
- [ ] 数据可溯源：每个数字/百分比/人名/头衔都有 source 出处（无源即废）
