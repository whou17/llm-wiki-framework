# Frontmatter 规范

## 标准格式

```yaml
---
title: [标题]
tags:
  - #一级标签
  - #二级标签
topics: [关键词1, 关键词2]
source:
  - xxx.md           # 最新来源置顶
  - yyy.md
  - zzz.md           # 最早来源在底
last-updated: 2026-06-07  # 自动维护
confidence: high | medium
status: active
related:
  - "[[相关页面]]"
---
```

## 字段规范

### 必须字段

| 字段         | 说明   | 维护规则        |
| ---------- | ---- | ----------- |
| title      | 页面标题 | 创建时确定       |
| tags       | 按需原则 | 按标签体系       |
| source     | 来源追溯 | **新来源置顶**   |
| confidence | 可信度  | high/medium |
| status     | 状态   | active/待审核  |

### 自动维护字段

| 字段 | 说明 | 触发时机 |
|------|------|---------|
| **last-updated** | 最后更新日期 | **每次知识入库时自动更新为当日** |
| **source** | 来源列表 | **新来源插入列表顶部** |

### 可选字段

| 字段 | 说明 |
|------|------|
| topics | 关键词搜索 |
| related | 关联页面 |
| open-questions | 标签提议/待解决问题 |
| contradictions | 知识冲突 |

## source 排序规则 ⭐

**核心原则：新来源置顶（倒序排列）**

```
正确示范：
source:
  - raw/sources/新学习的文件.md    ← 最新（置顶）
  - raw/sources/之前学习的文件.md
  - raw/policy/更早的文件.md       ← 最早（最底）

错误示范：
source:
  - raw/policy/文件1.md           ← ❌ 字母序
  - raw/policy/文件2.md
  - raw/sources/新文件.md         ← ❌ 新文件在底部
```

**原因**：快速追溯"这个知识点最近被哪篇文章更新"

---

## last-updated 自动更新机制 ⭐

**触发条件**：每次执行结构化学习并更新知识库时

**规则**：
- 更新为**当日日期**（格式：YYYY-MM-DD）
- 例：2026-06-07 执行学习 → last-updated: 2026-06-07

**示例**：
```yaml
# 学习前
last-updated: 2026-04-19

# 学习后（2026-06-07执行）
last-updated: 2026-06-07  # 自动更新
```

## 禁止格式

```
❌ tags:[#xxx]              # 单行写法，禁止
❌ last-updated: 未更新     # 未同步，禁止
❌ source: 混乱排序         # 不按时间顺序
❌ 正文重复元数据
```

## 正确示例

```yaml
---
title: 示例概念页
tags:
  - #一级标签
  - #二级标签
topics: [关键词1, 关键词2]
source:
  - raw/sources/最新来源.md  # 最新
  - raw/policy/既往来源.md
last-updated: 2026-06-07
confidence: high
status: active
related:
  - "[[相关页面]]"
---
```

---

## 学习流程中的frontmatter更新步骤

**每次执行结构化学习后，必须同步更新知识库文件的frontmatter：**

```
1. 读取目标知识库文件
2. 在 source 列表顶部插入新学习的源文件
3. 将 last-updated 更新为当日日期
4. 保存文件
```

## 来源类型说明

| 目录 | 类型 | 示例 |
|------|------|------|
| raw/sources/ | 外部资料/他山之石 | 外部经验、媒体报道 |
| raw/policy/ | 政策文件 | 上级文件 |
| raw/practice/ | 实践材料 | 会议讲话、总结 |
| raw/research/ | 理论研究 | 学术论文 |

**注**：不再使用单独的 source-type 字段，来源类型由目录隐含。
