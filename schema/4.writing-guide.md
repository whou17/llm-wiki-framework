# 写作总指引

> **定位**: 所有"撰写X"类任务的统一流程入口。范式知识在 `schema/4a`-`4e` 各体裁页（随 Knowledge-IN 摄入持续增长），本页只定义"怎么写"的稳定流程。
> **核心模型**: 写作任务 = **体裁范式 × 说话人画像** —— 范式解决结构/格式/语言框架（骨架），画像解决思维模式/语言风格/关注侧重（血肉），二者正交自由组合。画像建模标准见 `schema/5.persona-guide.md`。

---

## 一、触发映射（写作任务 → 范式页 × 画像）

**请求语法**：
```
"撰写[体裁]" → 对应 4x 范式 + 该体裁默认画像
"撰写[体裁]，以[画像]的视角切入" → 对应 4x 范式 + 指定画像
```

| 触发词 / 任务 | 范式页（骨架） | 默认画像（血肉，可替换） | 输出位置 |
|--------------|--------------|------------------------|---------|
| "撰写第一议题" / "写表态发言" | [[4a.pattern-first-agenda\|4a 第一议题表态]] | 党委书记画像 | wiki/synthesis/ |
| "撰写评论" / "写一篇评论" | [[4b.pattern-people-forum\|4b 人民论坛评论]] | 作者（[[人物-侯伟]]） | wiki/synthesis/ |
| "撰写立项申请书" / "科研立项书" | [[4c.pattern-立项申请书\|4c 科研立项申请书]] | 作者（[[人物-侯伟]]） | wiki/synthesis/ |
| （后续扩展：公文/书稿/学习心得） | 4d / 4e | 按场景指定 | wiki/synthesis/ |

> 画像不锁定体裁：任何已建画像（见 [[5.persona-guide\|schema/5]] §六 画像库）都能配任何范式。例："撰写第一议题，以[[人物-顾明远]]视角切入" = 4a 范式 + 顾明远画像（学术视角）。
> 新增一种体裁 = 加一页范式 + 本表加一行；新增一种画像 = 建人物画像页（schema/5 模板），均不动流程。
> **路由边界**：**简短表态发言**（第一议题表态等）走 4a 范式；**成体系公文/讲话稿/学习计划**（通知、实施意见、学习计划、正式讲话稿）走 `chinese-official-drafting` skill（`.claude/skills/chinese-official-drafting/SKILL.md`）。

## 二、通用执行流程（8 步）

```
[Step 1] 解析需求：体裁 + 画像（默认或指定）+ 主题/对象/场合/是否投稿
[Step 2] 读范式：Read 对应 schema/4x 范式页（结构/格式/语言骨架）
[Step 3] 加载画像：Read 指定画像页（默认用该体裁默认画像；"以X视角"则读X画像）——提取思维模式/语言风格/关注侧重/典型表述。⚠ 使用边界见 §四「画像使用边界」
[Step 4] 研究思考：Grep 知识库相关素材，定位选题/立意（"习以为常里藏着选题"）
[Step 5] 结构设计：按范式模板搭结构（三层递进），再按画像的思维模式/结构偏好微调
[Step 6] 成文：范式语言规范 + 画像思维/侧重/话语（复用典型表述库） + CLAUDE.md §四-B 输出格式 + §九 引文精度
[Step 7] 审校：见第三节清单，逐项过
[Step 8] 交付：写入 wiki/synthesis/ → 更新 index.md + log.md
```

## 三、审校清单（每稿必过，不可跳过）`CRITICAL`

```
□ 内容准确：引文与 source 一致？事实表述有据？
□ 数据可溯源 `HARD LIMIT`：文中每个具体数据（数字/百分比/人名/头衔/成果）都能在 source 或知识库找到出处？无源数据必须删除或改定性表述，绝不凭记忆补数
□ 引文纪律（CLAUDE.md §九 六条逐项过）：加引号=原文照录？数据限定条件（样本/时间/范围）保留？跨场合金句标注语境？转引标注原始出处？政策/模式归属准确（对象/地域/层级）？
□ 素材多元：综合政策依据+时事热点+数据+多方观点，**不得仅围绕单一人物观点/单篇文章反复引用阐述**（评论类点名引用某专家 ≤1-2 处，其余转"共识"或并置其他观点）
□ 关键点深挖：立意是否被充分支撑？是否点出问题卡点/痛点并一一破解？是否落到基层实践（政策依据+创新实践）？**忌"立意正确但阐述空泛"**（评论核心）
□ 风格一致：遵守范式 + 当次用户明确要求（禁AI腔/禁破折号等）？
□ 去AI味：见 §三-A 清单，逐项过（破折号清零/句式去模板/动词去同质化/意象词收敛/升华腔克制/引号节制）
□ 逻辑连贯：段落过渡自然？无逻辑跳跃？
□ 重复冗余：无同一表述跨段重复？
□ 引文核对：直接引语可在 source 找到原文？
□ 字数/格式：符合范式要求？如需 docx 走 §九-A 流程？
□ 画像匹配：复用画像的思维模式/关注侧重/话语体系？（见 §四 使用边界——**勿以其名义/第一人称口吻代笔**，除非范式本身要求画像发言）
```

> 完成标准：**写完后必须 Read 通读**，不可凭写作记忆判断质量；审校发现问题必须实际修复，不得只指出不修改。

## 三-A、去AI味语言规范 `CRITICAL`

> **设计原则**：AI 起草的文字有可识别的"AI 腔"——破折号密集、句式模板化、动词同质化、意象词堆砌、升华腔。投稿/公文体裁须逐项清除。以下清单由 2026-08-17 三篇评论去AI味实测沉淀（正文破折号 18→0）。

```
□ 破折号清零：正文破折号（——）原则上 0 处，改冒号/句号/拆句；专有名词内部连接符（如"新任—新秀—骨干"阶梯名）除外
□ 句式去模板：并列段落不得共用同一句式骨架（如连续三段"破解靠X"），每段换句式或差异化动词（入手/下手/发力）
□ 动词去同质化：多专家连续引用时，"指出/提出"等不得连用，按语境换"谈到/提醒/判断/透露/援引"
□ 意象词收敛：每篇保留 ≤2 个核心比喻（如"指挥棒""压舱石"），删"技术喧哗""育人底色"类堆砌性意象
□ 升华腔克制：删"让我们…""必将…""终将照亮…"式 AI 升华套话，改具体可感的收束（如"教育家精神一旦扎根泥土，自会枝繁叶茂"）
□ 引号节制：不给普通词滥用引号；引号只用于原文照录/专名/反语
□ 排比务实：排比每句须有实质内容，删"让…让…让…"式空洞三连
□ 连接词精简：删"不难发现""值得注意的是""某种意义上""在…的背景下"等 AI 高频连接套话
□ 数据叙事化：数据融入叙述而非堆砌罗列，单段关键数据 ≤3 个
```

### 示例

✅ **CORRECT**（具体收束）: "大先生从来不是被'评'出来的，而是在一方方课堂、一所所学校里'长'出来的。"
❌ **INCORRECT**（升华腔）: "让我们共同努力，让更多大先生涌现，为教育强国建设贡献力量！"

✅ **CORRECT**（句式差异化）: "破题从评价改革入手。……破题从减负下手。……破题从制度发力。"
❌ **INCORRECT**（模板化）: "破解靠评价改革。……破解靠减负。……破解靠制度。"

## 四、画像库（与范式正交的"血肉"轴）

画像建模标准见 **[[5.persona-guide|schema/5.persona-guide.md]]**（7 维模板 + 请求语法 + 构建更新机制）。当前画像库：

| 画像 | 状态 | 特点（一句话） |
|------|------|--------------|
| 党委书记画像 | 完整画像 | 空间隐喻 + 对标学习 + 三段式 + 四锚点底层操作系统 |
| [[人物-顾明远]]（教育专家） | 已补强画像 | 历史纵深 + 数据驱动 + 本质追问 + 金句化（8-16 摄入7篇专题补强，共8篇材料） |
| 其余 7 位人物页 | 基本信息 | 可升级为画像（摄入 ≥2 篇材料后按 schema/5 建模） |
| [[人物-侯伟]]（作者本人） | 完整画像 | 胜任工作论 + 政策思维（学语言→学思路→学规划）+ 概念先行 + 类比隐喻 + 金句化（8-17 由 raw/interviews/ 10 篇 2009-2026 材料建模） |
| 校长画像 | 雏形画像 | 施政理念方法论：五个要素评判公式 + 一院一策 + 学科四大行动 + 科研四个面向 + 职称杠杆论（2026-09-01 开学部署会 + 8-20 素材，未按 7 维建模，待补强） |

> 组合规则：**画像不绑定体裁**。写作时按 §一 语法指定画像；未指定用体裁默认画像。
> 学术大拿/政界领导等新画像摄入后，自动进入本库，即可参与任意范式的组合。

### 画像使用边界 `CRITICAL`

> **原则**：使用画像是**复用其思维方式、关注侧重、话语体系**（"像X那样想问题、关注X关注的问题、用X的话语表达"），**不是以X的名义/第一人称口吻替他发言**。
> 2026-08-16 修正动因：评论初稿曾以顾明远口吻写"我这一生从教七十余年"——错误地"替画像人物说话"。

**是否以画像名义署名，由范式类型决定**：

| 范式类型 | 画像角色 | 示例 |
|---------|---------|------|
| **以画像名义产出**（讲话稿/表态发言类） | 画像人物本身就是发言人，代写其口吻是任务本身 | 4a 第一议题表态（默认党委书记） |
| **以作者名义产出**（评论/署名文章类） | 画像仅提供思维/侧重/话语；作者视角叙述，画像观点作**引用素材** | 4b 人民论坛评论（如"以顾明远视角"→ 复其思维金句，不写"我这一生"） |

**执行要点**：
1. 成文前先判范式类型（§一 路由表 → 输出物是"谁"署名的稿）
2. 评论/署名类：画像的典型表述、金句作为**带引号的引用素材**（"如顾明远所期许：不当教书匠，要当教育家"），叙述主体始终是作者
3. 讲话稿类：才以画像第一人称成文（那是代写讲话，非评论）
4. 若范式未明示，默认**不以画像名义**，只用其思维/侧重/话语

## 五、增长机制：范式与画像的持续演进

> 写作范式库不是静态文件，而是随摄入材料持续生长的系统。两条闭环 + 定期复核，让画像与范式永远"被新材料喂养"。

### 闭环 A：画像构建与反哺（任何人物文稿/修改稿 → 建画像 / 更新画像）

**触发**：
- 用户提供某人（书记/学术大拿/领导）的讲话、稿件或**修改稿/终稿**
- Knowledge-IN 摄入时检测到"人物讲话/修改稿 + 已有同主题 synthesis 稿件"

**执行**：
1. **新画像构建**（该人物尚无画像）：收集 ≥2 篇材料 → 按 [[5.persona-guide|schema/5]] 模板建模 → 写入 `wiki/entities/人物-XX.md`（单篇→雏形页标注"待补强"）
2. **画像反哺**（已有画像 + 修改稿）：对增/删/改逐处识别（关注点/用词/结构/引用/语气/站位六维）→ 提取撰写思路、思维变化 → 新特征**追加**到该人物画像对应特征项（标注 `[新增于YYYY-MM-DD, 来源: XX/修改稿]`），不改旧内容
3. **联动**：若变化牵动结构/语言要点 → 同步更新对应 4x 范式；追加 `wiki/speech-comparison-log.md`（一次一记）
4. **产出**：一句话"画像/思维变化摘要"告知用户

**关键原则**：画像是"吸附点"——新信号追加、不推倒重建；修改痕迹是最高信号强度的信息（增删改 = 本人的主动选择，比公开表述更真实）。

### 闭环 B：范式新建（新体裁材料 → 新建 4x 范式页）

**触发**：用户提供新体裁材料（科研立项书、公文、学习心得、书稿章节等）。

**执行**：
1. **体裁识别**：摄入时判断材料体裁；检查 4x 系列是否已有对应范式
2. **无对应 → 提炼**：收集 ≥2 篇同体裁材料，提取共性（结构模板/语言要点/范例）
3. **新建**：`schema/4x.pattern-<体裁>.md` + 本页路由表加一行 + `schema/0.index.md` 登记
4. **单篇降级**：仅 1 篇材料时先建"雏形页"并标注 `[待补强：仅1篇材料]`，有第二篇再补强
5. **产出**：告知用户"已新建 4x 范式"

### 闭环 C：定期复核（健康检查）

Knowledge-LINT 时：
- 检查 4x 范式与最新 synthesis 输出是否一致（结构/语言是否已演进）
- 检查各画像（人物-XX）last-updated 是否超期（>60 天提示更新）
