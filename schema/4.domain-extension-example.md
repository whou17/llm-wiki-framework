# 领域扩展模板

> **定位**: 框架本身是领域无关的。当你在特定领域（高校管理、企业战略、政府政策等）深度使用时，可能需要添加领域专属的 schema 文件。本文件以"讲话稿撰写指引"为例，展示标准结构。

---

## 何时需要领域扩展

| 场景 | 是否需要扩展 | 说明 |
|------|------------|------|
| 通用摄入/检索/健康检查 | ❌ 不需要 | 框架自带的三 workflow 已覆盖 |
| 特定类型产出（如撰写讲话稿、生成报告） | ✅ 需要 | 创建 `schema/4.{domain}.md` |
| 特定决策者的偏好建模 | ✅ 需要 | 创建画像实体页 + 领域 schema |
| 特定机构的定制化流程 | ✅ 需要 | 在 CLAUDE.md 触发表中新增触发词 |

---

## 标准结构

一个领域扩展 schema 文件应包含以下板块（按顺序）：

```
---
title: [领域名称]
description: [一句话说明用途]
tags:
  - "#写作指引"        ← 使用已有标签或提案新标签
created: YYYY-MM-DD
last-updated: YYYY-MM-DD
type: spec
version: v1.0
confidence: low          ← 初始置信度，随验证次数提升
related:                  ← 互链相关文件
  - "[[人物-XXX]]"
  - "[[画像-XXX]]"
  - "[[comparison-log]]"
  - "[[schema/3.learning-methods]]"
---

# [标题]

## 一、触发条件
（什么时候读取此文件）

## 二、决策者画像（如有）
（按人物分板块，每人物包含以下子板块）

### 2.1 认知特征
（思维框架、关注领域、知识结构）

### 2.2 当前热点
（近期关注的话题、反复提及的概念）

### 2.3 语言风格
（句式偏好、修辞习惯、程序性用语）

### 2.4 写作偏好（基于对比证据）
（已验证的偏好，标注验证次数和来源）

### 2.5 待验证假设
（有信号但未充分验证的推测）

## 三、场合-文体映射
（不同场合的篇幅、结构、语气差异）

## 四、操作流程
（撰写/执行的具体步骤）

## 五、模板库
（可复用的模板，标注适用场景+来源对比）

## 六、版本历史
（记录偏好的演化过程）
```

## 实例：讲话稿撰写指引（高校管理场景）

> **说明**：以下是一个真实场景的简化示例，展示如何为特定决策者（党委书记）配置领域扩展。完整版会包含更多对比证据和模板。

### 一、触发条件

**自动触发**：
- Knowledge-IN Step 4 检测到特定作者 + 同主题稿件 → 自动切入对比模式
- 对比模式 C3 知识分流 → 自动更新本文

**手动触发**：
- 用户输入"写XX讲话" → 先读本文 + 画像 → 再执行撰写

### 二、决策者画像

#### 2.1 认知特征

| 维度 | 特征描述 | 证据来源 |
|------|---------|---------|
| **思维框架** | 系统思维，善于建立多维对标体系 | 第1次对比（2026-07-03） |
| **关注领域** | 粮食安全、学科建设、认证评估、硕士学位授权 | 同上 |
| **知识结构** | 高等教育管理 + 政策研究，熟悉全国高校动态 | 同上 |
| **信息渠道** | 掌握对标院校的学科布局和特色方向 | 同上 |

#### 2.2 当前热点

- 粮食安全学科群建设（对比三校：南财粮食学院、河工大粮油食品、肇庆学院粮食法治）
- 四项历史任务：硕士学位授权单位、更名师范大学、创建"双优"本科高校、教师教育能力提升工程
- 专业认证体系扩展：师范三级 + 工程教育 + 商科国际 + 教育数字化

#### 2.3 语言风格

| 特征 | 说明 | 验证次数 |
|------|------|---------|
| **部署性语言** | 倾向"希望XX牵头组织..."而非"建议XX考虑..." | 1 |
| **对标比较** | 引用其他高校做法作为参照系 | 1 |
| **会议程序完整** | 保留正式会议开场和领学环节 | 1 |
| **呼语偏好** | 首段用"："，结尾段用"，"（"同志们，"） | 1 |

#### 2.4 写作偏好（基于对比证据）

| 偏好 | 强度 | 验证来源 |
|------|------|---------|
| 引用式而非展开式（"引而不述+下步动作"模式处理上级政策） | 强 | 第1次对比：十五五规划处理方式 |
| 决策场合减少理论展开，增加任务指派 | 强 | 第1次对比：四有框架处理方式 |
| 政绩观与具体任务绑定 | 中 | 同上 |
| 结尾号召段有稳定偏好（逐字采纳率 60-70%） | 强 | 第1次对比：结尾段 |

#### 2.5 待验证假设

| 假设 | 信号 | 需验证 |
|------|------|--------|
| 是否每次都会新增对标院校分析？ | 第1次对比新增三校 | 再观察 2-3 次 |
| 是否持续删除品牌案例（如"齐民29号"）？ | 第1次对比删除 | 确认是否为场合适配 |

### 三、场合-文体映射

| 场合 | 理论:部署 | 篇幅 | 特点 |
|------|----------|------|------|
| **党委会** | ~2:8 | 精炼（~20行） | 决策导向，任务指派为主 |
| **理论学习中心组** | ~5:5 | 中等（~50行） | 学习导向，理论阐述+初步部署并重 |
| **专题调研** | 待观察 | 待观察 | 待观察 |

### 四、操作流程

撰写特定决策者的讲话稿时：

```
1. 读取本文 → 获取当前偏好和热点
2. 读取 wiki/entities/画像-{决策者}.md → 获取认知特征
3. 读取 wiki/comparison-log.md → 获取历次修改模式证据
4. 读取 wiki/entities/机构-{名称}.md → 获取战略框架和当前任务
5. 撰写初稿 → 应用已验证偏好
6. 终稿到达后 → 执行对比模式（C1-C6）→ 更新本文
```

### 五、模板库

#### 模板 1：结尾号召段

```
同志们，[当前任务]任务艰巨、使命光荣。让我们[动词]起来，
[三个并列短语]，齐心协力[目标]，不断[更高追求]。
```

> **来源**: 第1次对比，书记近乎逐字采纳（仅去掉"让"字）
> **适用**: 党委会结尾段

## 如何创建你自己的领域扩展

1. **复制本文件** → `schema/4.{your-domain}.md`
2. **替换示例内容** → 填入你的领域知识
3. **注册到 CLAUDE.md** → 在触发表和前置读取表中添加条目
4. **初始化置信度** → 所有偏好初始标记为 `confidence: low`，随验证提升
5. **建立对比循环** → 每次产出与终稿对比 → 更新偏好 → 提升置信度

### 关键原则

- **一个领域一个文件**：不要把所有领域偏好塞进一个文件
- **偏好需验证**：单次观察不标记为"已确认"，标注验证次数
- **区分事实与假设**：已验证偏好 vs 待验证假设，分板块存放
- **指针优于重复**：人物页通过 `[[wikilink]]` 引用领域 schema，不在两处维护相同内容

---

*本模板源自一个高校管理知识库的实战经验。对比模式首次执行（2026-07-03）即发现：决策场合的理论/部署比例、框架展开程度、对标院校引用等维度存在系统性的修改模式——这些都无法从公开讲话中获取，只能通过修改痕迹反向建模。*
