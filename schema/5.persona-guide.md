# 人物画像建模标准（Persona Guide）

> **定位**: 画像解决"以谁的思维、语言、侧重写作"（血肉），与范式（schema/4x，结构骨架）正交。
> 写作任务 = **体裁范式 × 说话人画像**。
> 权威来源：`schema/4.writing-guide.md` §四。

---

## 一、画像与范式的关系

| 维度 | 范式（4x） | 画像（本文件） |
|------|-----------|--------------|
| 解决什么 | 结构/格式/语言规范（骨架） | 思维模式/语言风格/关注侧重（血肉） |
| 存放 | schema/4x.pattern-*.md | wiki/entities/人物-XX.md |
| 提问 | "写什么结构" | "像谁在说话" |

两者自由组合：同一范式配不同画像 = 不同风格的同体裁稿；同一画像配不同范式 = 同一人写不同体裁。

### 画像使用原则（非以其名义）

> **使用画像 = 复用其思维方式、关注侧重、话语体系（典型表述/金句/修辞），而非以画像人物的名义/第一人称口吻替他发言。**
> 例：以顾明远画像写**评论**，是"像顾明远那样想教育问题、关注他关注的强师与育人、化用他的金句"，但叙述主体是作者——"顾明远认为…""正如顾明远所期许…"；**不可**写"我这一生从教七十余年"。
> 例外：**讲话稿/表态发言类范式**（如 4a）以画像名义产出是任务本身（那是代写画像人物的讲话）。
> 判别：成文前确认"本稿以谁署名"。评论/署名类 → 作者署名，画像只作思维/话语资源；讲话类 → 画像署名，代其口吻。详见 `schema/4.writing-guide.md` §四「画像使用边界」。

## 二、请求语法

```
"撰写[体裁]，以[画像]的视角切入" → 对应 4x 范式 + 指定画像
"撰写[体裁]"（未指定画像） → 对应 4x 范式 + 该体裁默认画像
```

示例：
- "撰写第一议题，以党委书记的视角切入" → 4a + 党委书记画像（默认）
- "撰写第一议题，以顾明远的视角切入" → 4a + 顾明远画像（学术视角）
- "撰写评论，以作者的视角切入" → 4b + 作者画像（默认）

## 三、画像建模模板（7 维）

每人物画像写入 `wiki/entities/人物-XX.md`，按以下维度：

**1. 身份站位**：以什么身份/立场说话（书记/学者/领导/教师），天然关注什么。

**2. 核心理念与价值锚点**：反复强调的根本判断、顶层逻辑（如党委书记"教育-科技-人才一体化"）。

**3. 思维模式**：怎么想问题——
- 隐喻基底（空间化/时间化/数字化…）
- 框架习惯（戴帽→分点→收束；每点内部逻辑链）
- 对标方式（借他山之石 / 独立设计 / 数据驱动）
- 处理异质信息的统一框架

**4. 语言风格**：核心修辞与高频句式；详引 vs 概引（内部草稿 vs 公开场合）；标点/引号习惯、段式节奏。

**5. 关注侧重**：什么问题排最前——议题优先级、关键抓手、反复出现的"硬仗"。

**6. 结构偏好**：几段式、如何开头（站位论证）、如何收束（号召/承诺）。

**7. 典型表述库**：高频词/金句/口头禅——写作时直接复用，是"像他说话"最直接的手段。

## 四、画像构建与更新（增长机制）

| 场景 | 动作 |
|------|------|
| 新画像构建 | 摄入某人 ≥2 篇材料 → 按本模板建模 → 写 人物-XX.md（单篇→雏形，标注"待补强"） |
| 画像更新 | 某人修改稿/终稿 → 对比增删改 → 追加画像特征（标注 `[新增于日期, 来源]`） |
| 定期复核 | 画像 last-updated 超期（>60天）→ 健康检查提示更新 |

> 详见 `schema/4.writing-guide.md` §五 增长机制（闭环A 已泛化到任意人物）。

## 五、模板范本：党委书记画像

> 完整画像见 党委书记画像「执政思想与管理理念画像」板块。以下为各维度填充示例：

| 维度 | 党委书记示例 |
|------|-----------|
| 身份站位 | 党委书记，党委立场 |
| 核心理念 | "教育-科技-人才一体化"（一核引领、四轮驱动） |
| 思维模式 | 空间隐喻（下沉/一线/嵌入/最后一公里）；对标学习型（先找他校跑通模板）+ **数据驱动对标**（软科十大模块35维度104项细分指标）；"戴帽→分点→收束"三段式；四锚点底层操作系统（正确政绩观/党建嵌入业务/实干实绩导向/对标外部参照） |
| 语言风格 | 核心修辞：一体推进/闭环/系统工程/久久为功/一条红线/到底到边见事见人；内部草稿详引、公开报道概引 |
| 关注侧重 | 申硕攻坚、十五五规划、学科筑峰、"跳出师范"转型、大抓基层、**"双优"创建、软科排名及细分指标**（十大模块35维度104项，首要诊断参照系，2026-09-01 补充） |
| 结构偏好 | 三段式，每点走"中央怎么说→我们怎么理解→学校怎么做" |
| 典型表述库 | 任务清单化/推进项目化/考核实效化；四下基层；最后一公里；党建引领的嵌入型治理 |
