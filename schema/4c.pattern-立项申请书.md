# 科研立项申请书写作范式

> 来源：《山东省高等学校哲学社会科学研究项目申报书（A表）》《申报书（B表）》（2026年度申报通知附件3/4）。2026-08-26 由山东省高校哲社研究项目申报入库时提炼。
> ⚠ `[待补强：仅1篇材料]` 本范式仅据 1 份申报书模板提炼，待有第二篇同体裁材料（其他省份/其他层级立项书）后按范式新建闭环补强。

## 适用场景

撰写山东省高校哲社研究项目（一般/专项）申报书，或同类省部级哲社课题立项申请书。默认由作者本人（[[人物-侯伟]]）申报。

## 体裁核心特征

1. **两表制**：A表（实名评审用）+ B表（匿名盲审用）。B 表不得出现单位、姓名等身份信息。
2. **课题名称硬约束**：准确简明，一般不加副标题，≤40 个汉字（含标点）。
3. **学科分类 24 类**：申报时必填其一（见模板）；分类须与选题归口匹配。
4. **课题论证五部分**（A/B 表共用提纲）：研究现状与价值 → 目标内容难点 → 思路方法计划 → 成果与去向 → 参考文献。
5. **研究基础三部分**（A 表实名）：主持项目情况 → 近三年成果（≤5 项）→ 资源保障；B 表须匿名改写。
6. **成果形式三选一（填字母）**：A.研究报告、论文；B.研究报告、决策咨询建议（需省级以上单位批示）；C.研究报告、其他。
7. **成员约束**：成员 ≤5 人（不含负责人），须实际参加研究；每人参与项目 ≤2 项；负责人限报 1 项。

## 结构模板

### A表（实名）

```
封面：学科分类 | 项目类别 | 课题名称 | 申请人姓名 | 所在单位 | 填表日期
数据表：课题名称/学科分类/项目类别/负责人信息/成员/预期成果(字母)/字数/完成时间
课题论证：
  1.研究现状，理论价值与应用价值
  2.研究目标，研究内容，重点难点
  3.研究思路，研究方法，研究计划
  4.研究成果与预计去向
  5.主要参考文献
研究基础：
  1.申请人主持科研项目情况（名称/来源/结项情况）
  2.近三年主要研究成果（≤5项，注明刊物/出版社/时间）
  3.资源与条件保障
申请人承诺（原文照录）
所在单位意见
```

### B表（匿名）

```
课题名称
论证提纲（同课题论证五部分）
匿名研究基础：
  6.主持人主持科研项目情况（匿名概述）
  7.近三年主要研究成果（只填名称/形式/作者排序，不填刊物/出版社/时间）
  8.资源与条件保障（匿名表述）
```

## 语言要点

- **课题论证**：研究现状综述须梳理研究脉络并指出不足（现有研究的三个缺口），价值分析分理论价值与应用价值两层；目标—内容—难点对应推进；思路—方法—计划落到可操作；成果与去向明确可检验。
- **制度表述**：涉及政策依据的制度定位句式原文照录并注明出处（CLAUDE.md §九 引文纪律）；数据无源即废 `HARD LIMIT`，宁用定性表述。
- **匿名改写规则**（B表）：
  - 删除单位名、姓名、头衔、刊物/出版社名、发表/出版时间
  - "本校/我校" → "高校"；"申请人所在单位" → 不出现
  - 项目来源表述用"校级/省市级/国家级课题"等层级化匿名说法
- **实证方法表述**：问卷规模、样本构成等数据保留限定条件（样本/时间/范围），不强化对比。

## 自检清单

- [ ] 课题名称 ≤40 字、无副标题
- [ ] 学科分类、项目类别、专项名称与选题匹配
- [ ] 课题论证五部分齐全、逻辑对应
- [ ] B 表全文无单位/姓名/刊物/时间等身份信息
- [ ] 引文加引号=原文照录；数据有源 `HARD LIMIT`
- [ ] 近三年成果 ≤5 项，A/B 表成果名称一致
- [ ] 成员 ≤5 人、每人参与 ≤2 项
- [ ] 参考模板：`raw/policy/科研-33`（A表）、`科研-34`（B表）
