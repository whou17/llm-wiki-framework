## 指令优先级速查

| 层级 | 标记 | 违反后果 |
|------|------|---------|
| 🔴 L1 | `HARD LIMIT` | 结果作废，需重做 |
| 🟠 L2 | `CRITICAL` | 结果质量严重下降 |
| 🟡 L3 | `IMPORTANT` | 结果质量部分下降 |
| 🟢 L4 | `GUIDELINE` | 可接受但非最优 |
