## 目录结构

```
claude/                   ← 工作流配置
├── CLAUDE.md            ← 总控指引

└── policy-organize.py   ← 制度文件梳理脚本

raw/                      ← 原始语料（不可变）
├── policy/              ← 政策文件
├── sources/             ← 外部来源
├── practice/            ← 实践材料
├── documents/           ← 内部文档
├── case-studies/        ← 案例
├── research/            ← 研究资料
└── interviews/          ← 访谈

├── entities/            ← 机构、人物实体
├── concepts/           ← 概念、知识点

schema/                  ← 规则索引
├── 0.index.md          ← 本文件
├── 1.frontmatter-spec.md
├── 2.tag-index-template.md
└── 3.learning-methods.md
```
