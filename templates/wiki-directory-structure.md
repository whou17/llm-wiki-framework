# Wiki 目录结构模板

将以下空目录结构复制到你的项目即可初始化 wiki 知识库。

```
wiki/
├── index.md              ← 导航中心 + 统计信息
├── log.md                ← 当月操作日志
├── open-questions.md     ← 待解决问题 + 标签提案
├── entities/             ← 机构、人物实体页
│   └── (按需创建)
├── concepts/             ← 概念、知识点页
│   └── (按需创建)
└── synthesis/            ← 综合分析产出
    └── (按需创建)
```

## 页面类型说明

### entities/ — 实体页

记录现实世界中的实体信息。典型实体类型：

| 前缀 | 示例 | 说明 |
|------|------|------|
| `机构-` | 机构-某某大学.md | 学校、企业、政府部门等 |
| `人物-` | 人物-某某.md | 个人简历、观点记录 |
| `内部-` | 内部-年度工作要点-2026.md | 所属机构的内部记录（三层分流） |

### concepts/ — 概念页

知识点的核心载体。按标签体系组织，每个页面聚焦一个概念，包含：
- 制度定位/基本定义
- 政策原文/权威来源
- 他方实践/案例
- 前沿观点

### synthesis/ — 综合分析

跨概念、跨领域的综合分析产出。通常由 Knowledge-OUT 流程触发，形成可复用的分析报告。

## index.md 最小模板

```markdown
---
title: Wiki 索引
---

# Wiki 索引

**更新时间**: YYYY-MM-DD
**页面总数**: N

## Concepts

| # | 名称 | 标签 | 状态 |
|---|------|------|------|
| 1 | [[示例概念]] | #标签 | ✅ |

## Entities

| # | 名称 | 类型 | 状态 |
|---|------|------|------|
| 1 | [[机构-示例]] | 机构 | ✅ |

## Synthesis

| # | 名称 | 主题 | 状态 |
|---|------|------|------|
| 1 | [[综合分析-示例]] | 主题 | ✅ |

## 统计

```
📊 当前状态 (YYYY-MM-DD)
├─ 页面总数: N
├─ Entities: N
├─ Concepts: N
└─ Synthesis: N
```
```

## log.md 最小模板

```markdown
---
title: 操作日志
---

# 操作日志 (Log)

**格式约定**: `## [YYYY-MM-DD] [operation-type] | [brief-title]`

此日志记录所有 wiki 操作。
```

## open-questions.md 最小模板

```markdown
---
title: 待解决问题
tags:
  - "#meta"
status: active
---

## 待解决

- [ ] 问题描述

## 已解决

- [x] 已解决的问题（保留记录）
```
