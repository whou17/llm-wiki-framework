# 微信文章提取与审校工作流

## 场景说明

用户发送微信公众号文章链接要求审校。微信文章通过 `web_extract` 提取时，会因编辑器格式残留产生特定类型的排版乱码，需要在审校时同步清理。

---

## Step 1：提取全文

使用 `web_extract(url)` 获取文章内容。微信链接通常形如：
```
https://mp.weixin.qq.com/s?__biz=...&mid=...&sn=...
```

> ⚠️ 微信链接参数很长，直接粘贴即可，无需截断。

---

## Step 2：识别格式乱码（微信特有）

### 2.1 星号残留（最常见）

**表现**：文字中间插入连续星号 `****`。

**成因**：微信编辑器加粗/高亮/颜色标记在提取时未正确解析，还原为纯文本星号。

**示例**：
```
实绩突****************出、****************成果丰硕
```
→ 应改为：**实绩突出、成果丰硕**

**处理**：直接删除所有连续星号，恢复被分隔的文字。

### 2.2 表格行前多余竖线

**表现**：Markdown 表格的某行前面多一个 `|`。

**成因**：`patch` 工具在替换文本时可能引入多余的前导竖线。

**示例**：
```
||| 13aa | [[四极]] |
```
→ 应改为：`| 13aa | [[四极]] |`

**处理**：删除多余的前导 `|`，使表格行格式与其他行一致。

### 2.3 中文逗号后多余空格

**表现**：中文标点后出现不应有的半角空格。

**示例**：
```
"地旅融智、服务大河"， 四维融合
```
→ 应改为：`"地旅融智、服务大河"，四维融合`

### 2.4 嵌套引号连写混淆

**表现**：两个相邻的单引号 `''` 难以判断分界。

**示例**：
```
打造'学理论强铸魂筑基''三学三强'学习体系
```
→ 建议加分隔：`打造"'学理论强铸魂筑基'——'三学三强'学习体系"`

---

## Step 3：逐段审校

按 `proofread-chinese` 主 skill 的三审制执行：

### 第一审：错别字与语病
- 全角/半角混用（中文标点必须全角，英文/数字半角）
- 数字规范（年份、百分比）
- 语病（主谓搭配、缺主语、句式杂糅）

### 第二审：人物身份与机构名称
- 姓名无误（形近字/同音字）
- 职务当前有效（调离/免职后不再使用旧职）
- 机构全称规范（"齐鲁师范学院"而非"师院"）

### 第三审：政治表述规范性
- 对照标准表述库逐条核对
- 重点检查：习近平相关表述、党的二十大/三中全会、教育类表述

---

## Step 4：数据核实

对文中出现的**数字、比例、排名、获奖**等数据性内容，逐条核实：

| 核查项 | 方法 |
|--------|------|
| 百分比变化（如"提升X个百分点"） | 验证差值计算：59.7% - 43.02% = 16.68% ✅ |
| 奖项名称 | 搜索确认：如"挑战杯"省赛特等奖 |
| 项目数量、经费金额 | 确认数量级合理，无小数点错位 |
| 媒体报道 | 确认媒体名称正确（光明日报、学习强国等） |
| 时间跨度 | 确认文中时间线与事件实际发生时间一致 |

> ⚠️ **百分比验证常见陷阱**：百分比变化有两种表述——"提升X个百分点"（绝对值相减）与"提升X%"（相对比例）。如原文说"提升16.68%"，应验证是百分点还是百分比。示例：59.7%比43.02%在数值上提升了16.68个百分点，但相对提升比例为(59.7-43.02)/43.02≈38.8%。

## Step 5：输出审校报告

### 报告格式

```
## 审校意见

**文章标题**：[标题]
**文章性质**：[类型说明]

---

### 一、硬伤（必须修改）

[序号]. **[类型]** — [位置]
> [原文]
→ [修改建议]
[说明]

### 二、格式与序号问题（建议修改）

### 三、标点与表达问题（可优化）

### 四、内容核实

| 项目 | 原文 | 判定 |
|------|------|------|
| 数据1 | xxx | ✅/❌ |

### 审校汇总

| 序号 | 类型 | 严重程度 | 位置 | 修改建议 |
|------|------|----------|------|----------|
| 1 | xxx | 🔴 必须修 | | |
| 2 | xxx | 🟡 建议修 | | |
| 3 | xxx | 🟢 可优化 | | |
```

### 严重度分级

| 标记 | 含义 | 处理要求 |
|------|------|---------|
| 🔴 必须修 | 事实错误、政治表述错误、星号乱码 | 发布前必须修正 |
| 🟡 建议修 | 序号不一致、逻辑矛盾、引号混淆 | 建议修改 |
| 🟢 可优化 | 标点微调、措辞润色 | 可改可不改 |

## Step 6：系列文章审校（新增）

当用户连续发送同一系列的多篇文章要求审校时（如"奋进师院—高质量发展巡礼"系列），应：

### 6.1 识别系列共性格式问题

- 同一系列的编辑模板相同，格式问题往往**跨篇重复出现**（如标题格式、编者按写法、副标题加粗等）
- 已在前篇发现的问题（如星号残留、多余空格），**优先在后篇同类位置检查**

### 6.2 保持报告风格一致

- 同一系列的审校报告应使用统一的分类框架和严重度标准
- 便于用户对照处理

### 6.3 避免重复提系列固定格式

- 系列文章共用的固定栏目元素（如"往期精彩回顾"、编辑署名信息等）不属于内容问题，不列入审校报告

---

## 已知陷阱

1. **提取不完整**：web_extract 可能丢失图片、特殊排版、SVG/动图。如果文章内容明显残缺，改用 browser_navigate 获取。
2. **动态加载内容**：部分微信文章有懒加载图片，提取后图片位置显示为 `![]()`，这是正常的提取限制。
3. **摄影/撰稿署名**：文章末尾的编辑、摄影、初审、复审、终审信息需保留，不视为内容问题。
4. **系列文章统一风格**：同一系列的格式问题可能反复出现，建议排查后统一反馈。
5. **百分比表述歧义**：注意区分"提升X个百分点"与"提升X%"，前者是绝对值相减，后者是相对比例。
