# 中文党政公文/讲话稿起草（Chinese Official Drafting）

## 触发条件

用户要求起草正式党政文稿：
- "以党委书记/校长视角写一段讲话"
- "起草学习××文件的通知/计划/实施意见"
- "写第一议题学习发言"
- "围绕××文件，提出几点要求"
- 结合知识库（Obsidian）和 web 检索的公文产出类任务

## 核心工作流

1. **核实政策依据（seek-truth）**
   - web_search 官方文件全称、文号、中央部署原文（新华社/人民网/共产党员网/教育部官网）
   - 内部文件（如省级转发通知）正文不公开时，以中央配套文件（中办通知、中央领导小组会议部署、总书记文章）为权威依据，并在起草说明中标注"全文为内部文件，以中央部署精神为框架"
   - 引文必须一字不差：总要求、固定表述（如"立党为公、为民造福、科学决策、真抓实干"）

2. **调取知识库（Obsidian）**
   - 读相关概念页（如 wiki/concepts/政绩观.md、第一议题制度.md）
   - 读学校实际素材（wiki/synthesis/、raw/practice/）——校情数据、阶段目标、已有提法

3. **起草**
   - 用户身份视角：党委书记 / 校长 / 二级学院书记……语气与站位相应
   - 场景锚定：党委会"第一议题"、理论学习中心组、民主生活会、专题研修班等
   - 结构：先意义、后要求；或先背景、后部署

4. **审校（proofread-chinese）**：政治表述规范性、职务身份、引文准确

5. **交付（双轨）**
   - 知识库：存入 wiki/synthesis/（综合页），更新 wiki/index.md（S 表 + 页面总数 + 最后操作）
   - Web：pandoc 转 docx → pemee.cn /materials/download/ 供下载（pemee.cn 网页部署属外部工作区能力，本库不内置；如需另行配置）

## 🚨 用户风格偏好（硬性要求）

> **"太长了，凝练成两个自然段"** — 用户对讲话稿/公文有明确的篇幅偏好，已多次纠正（2026-07/2026-08 实测）。

**默认形态：两段式讲话稿**

- 段落一（背景与意义）：点明学习文件、中央部署背景、总书记核心论述、结合本校阶段的形势判断
- 段落二（要求与部署）：总要求 + 具体措施（学查改等）+ 责任落实 + 与中心工作结合

**执行规则**：
- 先给完整版（首次起草可以展开）→ 若用户要求凝练，**直接产出两段式**，不再问"要几段"
- 两段式里每个要点用一句话收束，宁可合并也不要小标题分列
- 用户说"太长了"时**不要再给第三种折中长度**，直接给两段
- 学习计划/实施意见等**结构性文件**例外：保留分专题/分条目结构（用户未对结构类文件要求两段），但每个专题的描述要克制

## 🚨 学习计划/实施方案类文件偏好（2026-08 实测，两次修正）

> 起草学习计划时，**先判断学习教育所处阶段**再定整体定位。用户两次纠正均与此有关。

**1. 阶段定位必须精准**：若学习教育已开展半年、专班已运转，本次学习属于**收官阶段**——计划定位应是"**深化学习教育成果转化固化**"而非"动员部署"：
- 标题/总体要求体现"已进入巩固深化的关键阶段""学习教育收官阶段"
- 重心落在"把有效做法上升为制度规范、把查摆整改成果固化为长效机制、防止'收官即收场'"
- 与已有专班衔接：明确"专班继续发挥统筹协调作用，与前期学习教育有机衔接"

**2. 专题宁整合勿过细**：用户明确反馈"学习专题分得过细，可以适当整合"。起草时默认合并同类项：
- 6 个专题 → 4 个：①根本问题（总纲）②为民造福/功成不必在我（价值取向合并）③从实际出发/真抓实干（方法论合并）④学查改一体/建章立制（落脚点）
- 若手上有文件目录/案例清单（如《生动实践》16 案例），按"民生类 / 打基础利长远类 / 作风类 / 总纲类"归并到专题下，**不要一个案例一个专题**

**3. 目录截图驱动专题设计**：用户发来文件目录图片时，先 OCR 提取目录（放大 2-3x + 裁剪分区，OCR 流程见 CLAUDE.md §二 Step 2-C 或 .claude/skills/pdf），把案例/条目按主题归并到专题——这是调整学习计划的第一手依据。

## 常见坑

- **引用未公开的具体章节/专题号**：内部文件的附件编号、论述摘编的具体专题标题未公开时，不要写死（如"论述摘编第六、七专题"），改为"相关专题"或"关于××的论述"
- **文件名称与文号**：转发文件要区分"××转发《××》的通知"层级；文号用六角括号〔2026〕9号
- **用户姓名纠错**：来源文字中的"习进平"须纠正为"习近平"（原始 OCR/转录错误）
- **篇幅失控**：起草时默认两段式骨架，先写两段，不要先写长文再压缩
- **CDN 缓存导致用户下载到旧版**：pemee.cn 经 Cloudflare 代理，docx 等文件更新后用户可能仍下载旧版（`cf-cache-status: HIT`、`age` 头可确认）。解决：下载链接加版本参数（`?v=YYYYMMDD` 或 `?v=YYYYMMDDb`）强制绕过缓存；验证时用带参数的 URL 下载并检查内容标记（如"16个重大实践案例"字样）。
